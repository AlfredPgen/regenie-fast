HTSlib. regenie-4.1.3-fast contains HTSlib 1.18 (https://github.com/samtools/htslib/releases/tag/1.18),
built with: libcurl=yes S3=yes GCS=yes libdeflate=no lzma=yes bzip2=yes plugins=no.
regenie-4.1.3-official contains HTSlib 1.12 (https://github.com/samtools/htslib/releases/tag/1.12), whose
LICENSE file has the same terms (only the copyright years differ: 2012-2020 instead of 2012-2023).
Below: HTSlib 1.18 LICENSE, then htscodecs/LICENSE.md (the CRAM codecs bundled with HTSlib).
